# 滚动动效与视差

动画集中在 `src/composables/useLandingMotion.ts`，使用现有 GSAP 与 ScrollTrigger，无额外动画依赖。

## 场景编排

- 首屏：算珠以不同滚动速度和旋转幅度移动；算盘从轻微景深逐渐展开；标题层向远处退让。
- 导航：向下滚动后轻微收拢，底部细线表示页面阅读进度。
- 数字：08、09、02 以错开的翻入效果出现，数字本身保持真实。
- 材质：算珠特写和算盘反向视差；点击材质后，特写和文案重新编排入场。
- 功能：应用画面随滚动轻微漂移；切换标签时，文案和画面依次入场。
- 标语：宽屏且高度足够时，短暂停驻约 0.85 个视口的滚动距离；文字逐词显现，左侧算珠随进度靠拢。手机、平板和矮屏保持正常流式布局。
- 账簿：书页由轻微旋转和倾斜逐渐展开，三步记账的编号依次点亮。
- 下载：应用图标随页面接近底部缓慢浮起并旋转。

## 响应与清理

`gsap.matchMedia()` 根据屏幕尺寸和 `prefers-reduced-motion` 重建、撤销动画与 pin spacer。小屏位移为桌面的 30%，不固定停驻；减少动态效果时，去掉视差与固定停驻，文字直接完整显示，区块仅使用淡入。

滚动动画只改变 transform 和 opacity。普通区块入场继续由 IntersectionObserver 触发。未加入自定义滚轮拦截或未经节流的 scroll 监听。

每个图层只由一个持续滚动动画控制，材质切换和功能切换在独立子层完成。图片加载、字体就绪、FAQ 筛选和内容尺寸改变后，会合并刷新 ScrollTrigger。组件卸载时撤销上下文并移除观察器、监听器及延时任务。

## 验证

- TypeScript 与 Vite 生产构建。
- 1280 × 900：首屏视差 transform 随滚动变化，标语固定在约 120px，逐词 opacity 随进度增加。
- 390 × 844：无 pin spacer、无横向溢出，菜单、材质选择、归零、键盘拨珠和标签切换保留。
- 1280 × 600：取消固定停驻；恢复 900px 高度后只创建一个 pin spacer。
- 临时媒体查询测试场景：减少动态效果时无 pin、无首屏 transform，全部标语词可见；切回完整动画创建一个 pin，再次关闭恢复静态。测试入口已删除。
- 浏览器控制台检查。

参考：[ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) 与 [gsap.matchMedia](<https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/>)。

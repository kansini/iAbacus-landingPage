# 明暗主题

## 入口与配色

悬浮导航中的圆形外观按钮切换浅色与深色，图标旋转反馈当前外观。手机菜单打开时也可使用。隐私政策、技术支持、使用条款和静态 404 均有同样的切换入口。

- 深色：保留炭黑背景、青玉绿强调色。
- 浅色：宣纸白背景、深玉绿强调色。
- 图标、文字、卡片、导航玻璃面、菜单、筛选状态、FAQ 和下载按钮都使用语义颜色变量。
- 算盘、账簿和 AppGallery 等真实产品/品牌图片保持原样，不使用图片反相滤镜。

主题变量集中在 `public/theme.css`。共享初始化和切换逻辑位于 `public/theme.js`，Vue 入口组件是 `src/components/ThemeToggle.vue`。

## 行为

首次访问跟随 `prefers-color-scheme`，手动选择后以 `iabacus-theme` 键保存在浏览器本地。刷新、进入静态页面和同源标签页间保持一致。没有手动偏好时继续跟随系统变化。脚本在样式绘制前设置根元素的主题和 color-scheme，避免先显示另一套配色。

点击切换时，支持 View Transition 的浏览器执行约 0.5 秒的整页交叉淡入，图标用相同缓动旋转。兼容浏览器使用普通透明度过渡；减少动态效果时立即切换，不执行页面转场。动画只改变 opacity 与 transform，主题切换不重建页面，不改动滚动位置或 GSAP 的 pin 布局。

主题按钮有动态操作标签、按下状态、忙碌状态及键盘焦点样式。切换不移动焦点。本地存储被限制时仍能切换当前页面，不显示不必要的错误弹窗。
